TAREA 1: Integración de la red neuronal EfficientNetB4 en el backend
         con reconocimiento si es perro o no
================================================================================

ESTADO: ✅ COMPLETAMENTE IMPLEMENTADO

--- DÓNDE ESTÁ EL CÓDIGO ---

1. Modelo entrenado (archivo físico):
   WOOF_TRAINING/output/woof_model_v1.h5        ← modelo H5 usado por el backend
   WOOF_TRAINING/output/woof_model_v1.tflite    ← versión TFLite (opcional)
   WOOF_TRAINING/output/woof_model_v1_metadata.json ← metadatos del modelo
   WOOF_TRAINING/woof_training_v1.ipynb         ← notebook de entrenamiento

2. Carga del modelo en el backend:
   WOOF_BACKEND/app/services/model_service.py

   - Función load_model(): carga woof_model_v1.h5 al iniciar el servidor
   - Arquitectura: EfficientNetB4 (ImageNet pretrained) + cabeza de clasificación
   - Modelo de embeddings: toma la capa penúltima → vectores de 512 dimensiones
   - Preprocesamiento de imagen: resize a (380, 380), usa EfficientNet's preprocess_input

3. Función de reconocimiento si ES perro o NO:
   WOOF_BACKEND/app/services/model_service.py
   → Función: is_dog(image_bytes)
     - Recibe bytes de imagen
     - Preprocesa a (380, 380)
     - Corre el modelo de clasificación
     - Umbral de confianza: 40%
     - Retorna: True/False + porcentaje de confianza

4. Endpoint que expone esta función:
   WOOF_BACKEND/app/routes/dogs.py
   → POST /api/v1/validate-photo
     - Recibe: foto (multipart) + Bearer token Firebase
     - Llama internamente a is_dog()
     - Retorna JSON: { "is_dog": true/false, "confidence": 0.87, "message": "..." }

5. Inicialización del modelo al arrancar el servidor:
   WOOF_BACKEND/main.py
   → Función lifespan(): llama a load_model() antes de aceptar requests

TAREA 2: Configuración del proyecto FastAPI + Firebase Admin SDK + Cloudinary
         + Diseño INICIAL de la BD Firestore
================================================================================

ESTADO: ✅ COMPLETAMENTE IMPLEMENTADO

--- DÓNDE ESTÁ EL CÓDIGO ---

1. Proyecto FastAPI configurado:
   WOOF_BACKEND/main.py                         ← app FastAPI con lifespan, CORS, routers
   WOOF_BACKEND/app/config.py                   ← Settings con pydantic-settings, lee .env
   WOOF_BACKEND/requirements.txt                ← todas las dependencias
   WOOF_BACKEND/.env                            ← variables de entorno (credenciales)

   Dependencias clave en requirements.txt:
     fastapi, uvicorn[standard], python-multipart, pydantic-settings, python-dotenv

2. Firebase Admin SDK integrado:
   WOOF_BACKEND/app/services/firebase_service.py
   → Función: inicializa firebase_admin con credentials del .env
   → Función: upload_photo() → sube foto y retorna URL

   WOOF_BACKEND/app/dependencies.py
   → Función: verify_firebase_token()
     - Lee el header Authorization: Bearer <token>
     - Verifica token con firebase_admin.auth.verify_id_token()
     - Retorna decoded token o lanza HTTP 401

3. Cloudinary integrado:
   WOOF_BACKEND/app/services/firebase_service.py
   → Usa cloudinary SDK
   → Función upload_photo(image_bytes, folder) → retorna secure_url de Cloudinary
   → Configurado con cloud_name, api_key, api_secret del .env

4. Diseño INICIAL de la BD Firestore — 3 colecciones:

   COLECCIÓN: users/{uid}
   → Campos: uid, name, email, role("USER"/"ADMIN"), isBlocked, phone, fcmToken
   → Se crea cuando un usuario se registra (desde la app Android)
   → Código app: PROYECTO_APP/.../data/repository/AuthRepositoryImpl.kt

   COLECCIÓN: lost_dogs/{id}
   → Campos: name, description, owner_name, owner_phone, owner_email,
             photo_url, embedding (vector 512 floats), registered_by_uid,
             created_at, status("active")
   → Se crea al reportar perro perdido
   → Código backend: WOOF_BACKEND/app/services/firebase_service.py → save_lost_dog()

   COLECCIÓN: found_dog_reports/{id}
   → Campos: found_by_uid, created_at,
             matches: [ { dog_id, similarity_percent }, ... ]
   → Se crea al reportar perro encontrado con sus resultados de matching
   → Código backend: WOOF_BACKEND/app/services/firebase_service.py → save_found_report()
